# Подписчики сообщества VK по букве фамилии

Скрипт забирает участников сообщества через метод [`groups.getMembers`](https://dev.vk.com/ru/method/groups.getMembers) и записывает в CSV тех, чья фамилия начинается на заданные буквы.

В список попадают участники, которые не скрыли членство в этом сообществе. Удалённые и заблокированные страницы пропускаются. Полный состав отдаёт именно `groups.getMembers`: поиск `users.search` всех участников не возвращает, поэтому скрипт его не вызывает.

## Требования

- Python 3.11 или новее
- Ключ доступа ВКонтакте: пользователя, сообщества или сервисный

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Откройте `.env` и вставьте ключ в `VK_TOKEN`.

## Ключ доступа

Для своего сообщества проще ключ сообщества:

1. Откройте сообщество, которым управляете.
2. Перейдите в Управление → Настройки → Работа с API.
3. Создайте ключ и скопируйте его в `VK_TOKEN`.

Для чужого открытого сообщества нужен ключ пользователя. Его выдаёт [VK ID](https://dev.vk.com) приложению, созданному в кабинете разработчика. Скрипт сам авторизацию не проходит: в `.env` кладётся уже полученный ключ.

Закрытое сообщество отдаёт состав только ключу, у которого есть к нему доступ.

## Запуск

Буквы и сообщество можно задать в `.env` или аргументами. Аргументы перекрывают файл.

```bash
vk-members --group club123 --letters "А,К,М" --output members.csv
```

Тот же запуск из переменных, если `VK_GROUP_ID`, `VK_LETTERS` и `VK_OUTPUT` уже заполнены:

```bash
vk-members
```

Пока скрипт идёт, в stderr пишется прогресс: сколько человек уже получено и сколько попало в файл. Готовый CSV лежит в `members.csv` (или в пути из `--output`). Кодировка UTF-8 с BOM, чтобы Excel открыл кириллицу. Колонки: `id`, `first_name`, `last_name`, `domain`, `url`.

Повторный запуск перезаписывает файл. Если API оборвётся посередине, в файле останется уже записанная часть.

## Как сравниваются буквы

Сравнение идёт по первой букве фамилии без учёта регистра. «Ё» считается как «Е». Латинская «A» и кириллическая «А» — разные буквы, в список кладите кириллицу.

```bash
vk-members --group club123 --letters "Е" --keep-yo
```

`--keep-yo` оставляет «ё» отдельной буквой.

`А,К,М`, `АКМ` и `А К М` означают одно и то же: три буквы. Запись `А-Я` не раскрывается в алфавит, из неё берутся только «А» и «Я».

## Лимиты

За один запрос API отдаёт не больше 1000 участников, дальше скрипт листает список сам. Пользовательский ключ — около 3 запросов в секунду, поэтому пауза по умолчанию `0.35` секунды. У ключа сообщества лимит выше: паузу можно уменьшить через `VK_REQUEST_DELAY` или `--delay`. Ошибки «слишком часто» и внутренние сбои скрипт повторяет с увеличивающейся паузой.

## Коды выхода

- `0` — файл записан
- `1` — ошибка API или сети
- `2` — не хватает ключа, сообщества или букв
